# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application.

Users can browse different categories of houseplants, view plant names, prices and images, add plants to a shopping cart, change quantities, remove products and view the total cost.

## Features

- Plant browsing
- Multiple plant categories
- Add to Cart functionality
- Redux shopping cart management
- Dynamic cart item count
- Increase and decrease item quantities
- Remove items from cart
- Dynamic item and cart totals
- Checkout placeholder
- Continue Shopping functionality
- Responsive user interface

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS
